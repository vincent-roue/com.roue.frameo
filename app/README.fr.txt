Depuis Homey Pro, envoyez vos photos à un cadre Frameo ou à un groupe de cadres. Sélectionnez une image JPEG ou PNG sur votre téléphone, ou automatisez vos envois à partir d’une URL ou d’un tag image dans un Flow. Parcourez la galerie, choisissez une photo à afficher sur le cadre ou ajoutez un widget photo à votre tableau de bord.

Cette application communautaire indépendante nécessite un système Homey sous Linux ARM64 ou AMD64 avec le logiciel Homey 12.9.0 ou ultérieur. Les essais avec un cadre réel ont porté sur Homey Pro (2023) et un cadre Pexar. La validation de Homey Self-Hosted Server avec un cadre reste à faire. Appairez le cadre avec son code d’amitié. Pour la galerie, les widgets et les compteurs de médias, autorisez l’expéditeur Homey à consulter les photos dans Paramètres → Mes amis sur le cadre. Pour afficher, masquer ou supprimer une photo, autorisez aussi la gestion des photos.
