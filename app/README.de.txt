Sende Fotos von Homey Pro an einen Frameo-Bilderrahmen oder an eine Gruppe von Rahmen. Wähle ein JPEG- oder PNG-Bild auf deinem Smartphone oder automatisiere den Versand per URL oder Bild-Tag in einem Flow. Stöbere in der Galerie, wähle ein Foto zur Anzeige auf dem Rahmen oder füge deinem Dashboard ein Foto-Widget hinzu.

Diese unabhängige Community-App benötigt ein Homey-System mit Linux ARM64 oder AMD64 und Homey-Software 12.9.0 oder neuer. Tests mit einem echten Bilderrahmen wurden auf Homey Pro (2023) mit einem Pexar-Bilderrahmen durchgeführt. Homey Self-Hosted Server muss noch mit einem echten Bilderrahmen getestet werden. Kopple den Rahmen mit seinem Freundschaftscode. Erlaube dem Homey-Absender für Galerie, Widgets und Medienzähler das Ansehen von Fotos unter Einstellungen → Meine Freunde am Rahmen. Zum Anzeigen, Ausblenden oder Löschen eines Fotos ist auch die Berechtigung zur Fotoverwaltung erforderlich.
